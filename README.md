# Attacker Constellation

A year of web attacks reaching Japan, replayed on a world map.

https://infraredgk.github.io/attacker-constellation/

- Light from each source toward Japan: probing, exploit attempts, SQL injection and web-shell attempts.
- Countries glow and capitals raise pillars by relative sending volume.
- Lines join sources that probed alike (estimated attack groups).
- Bot storms are shown with the flags of every country they came from.

The data is aggregated and anonymized: positions are rounded to a 2° grid, times are shifted, and only relative intensity is kept. No counts, addresses, paths or target names are included.
